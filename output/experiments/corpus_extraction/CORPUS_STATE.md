### Filename normalization (2026-09-23)

Case filenames are generated by the extractor from `metadata.neutral_citation`
(`[YYYY] COURT NUM` → `YYYY_COURT_NUM.json`). Because the citation was captured **before**
the clean-up, the 235 citation-patched cases carried stale names (extra action numbers,
law-report series, party names, …), e.g.:

| old filename | new filename | citation |
|---|---|---|
| `1969_HKCFI_66_HCA_447_1968.json` | `1969_HKCFI_66.json` | `[1969] HKCFI 66` |
| `1988_HKC_795.json` | `1988_HKCFI_461.json` | `[1988] HKCFI 461` |
| `LEE_YUK_LAN_v_…_1999_HKCFI_364_HCPI_187_1995_5_August_1999.json` | `1999_HKCFI_364.json` | `[1999] HKCFI 364` |

**235 files renamed** (0 collisions); the other 1,245 already matched. Every case file now
resolves to exactly `YYYY_COURT_NUM.json` for its neutral citation. `progress.csv`,
`qc/applied_patches.csv`, `qc/psych_false_positives.json`, and the parallel
`cases_backup/` entries were updated in step. Full old→new map:
`qc/renamed_files.csv`.

## 7. Reproduce

```bash
# 1. Audit (deterministic, no LLM)
uv run psla audit-corpus

# 2. Validate every case against the schema
uv run python -c "import json,glob; from hklii_psla.schemas import Case; \
[Case.model_validate(json.load(open(p))) for p in glob.glob('output/experiments/corpus_extraction/cases/*.json')]; \
print('all valid')"

# 3. Tests
uv run pytest tests/ -v

# 4. Coarse ICD pass (deliberately NOT run yet; needs a model + tuned coarse_nodes.json)
uv run psla patch-corpus --ops coarse --provider gpt --select COARSE_ICD_NODE
```

Re-running the deterministic `citation` / `psych` ops against the current cases is a
**no-op except for the 7 documented false positives** — the clean-up is fully applied.
